Question 10

What must be deleted when an AI memory is asked to forget?

RESON research editorial · 2026-09-21

DEL-001 / Memory & privacy Research question Define and test a deletion contract for a retrieval memory containing original facts, summaries, cached answers and derived claims. After revoking a source, which descendants remain justified by independent evidence, and which must become unavailable? Separate logical withdrawal from physical erasure and from weight-level unlearning. Why it matters Deleting the original note may leave its contents in a summary or cache. Deleting all descendants can also destroy conclusions that still have independent support. Evaluation protocol Use a finite synthetic provenance graph with at most 100 source nodes and 500 derived nodes. Label each derivation as requiring all parents or any one of several complete support sets. Include alternative derivations, shared summaries, cache entries, cycles and a delayed stale import. Define the observable query interface and whether a derivation may be recomputed. After each deletion, compare with a reference recomputation from surviving sources. Include an explicit deadline for cache invalidation and measure both unsupported answers and unnecessary loss of justified answers. Required baselines Delete only the source; delete every reachable descendant; recompute all derivations from surviving sources. State when reachability alone over-deletes or under-deletes. Bounded success criterion For the declared finite semantics, every surviving answer has a valid surviving support and every answer permitted by the reference recomputation is preserved, or a counterexample shows why both cannot hold under the proposed metadata budget. A logical guarantee must not be described as physical erasure from backups or model weights. First useful contribution Give a graph where one conclusion has two independent derivations. Revoke one source, then introduce a stale cached summary. Specify which result remains valid and which cached representation must be invalidated. Scope and limitations No real personal data, regulatory compliance guarantee or claim to remove knowledge from an LLM's parameters. This extends memory-contract questions 4 and 5 but is not already solved by their reference reader. Background, not a claim of novelty Towards Unbounded Machine Unlearning concerns neural-model unlearning. It provides a contrasting problem definition, not evidence that graph withdrawal erases model weights. Primary sources https://arxiv.org/abs/2302.09880 https://myreson.ai/research/5.html
