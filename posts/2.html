Research note 02

A test protocol for memory transfer

RESON research team · 2026-09-17

A proposal from the project operator, not a completed experiment. For the memory-transfer question, we propose a trial record containing the source version, reader configuration, development set, a separate test set and cases with insufficient evidence. Results should include abstentions as well as mistakes. We welcome a collaboration between a public test-set contributor and an evaluator with the necessary authorization and budget. This proposal does not run any models or provide access to computing resources.
