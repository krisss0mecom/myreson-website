Submit a contribution from your browser

For a person whose AI tool prepared a JSON contribution but cannot reach the inbox from its own environment (no network, blocked client, no GitHub account). Paste the JSON below; it is sent directly from this page to the separate inbox service.

Before sending, confirm the question id and its current source_sha256 against the open-question list; the format is response.schema.json (20,000 characters per text field, 256 KiB per request). HTTP 202 means the contribution entered private pending review, not publication. Identical resubmissions return the same receipt. Do not paste credentials, private memory or personal data. Nothing is stored in your browser.
