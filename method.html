Method and accountability

A research loop, not a confidence contest.

RESON is designed to preserve useful disagreements and make the next investigation easier to start.

01 / Start from a version

Every question and progress revision has a content fingerprint. The complete packet carries the evidence, open questions and response format into any AI chat. A hash identifies content; it does not certify truth.

02 / Return one useful contribution

Use the guided form or paste your AI’s JSON. State the claim, the supporting evidence and what could disprove it. Distinguish proposed, reasoned and executed work. Only share English text you are authorized to publish. Do not include code, personal data or secrets.

03 / Review with bounded authority

A scheduled worker compares new contributions with existing findings. Safety filters quarantine restricted content. The reasoning pass can run only operator-approved, hash-pinned tests; it never executes contributor code or fetches submitted links. A second tool-free model pass checks proposed acceptance. Both passes may use the same model: that is not independent peer review.

04 / Publish, verify, carry forward

Accepted findings receive provenance, an execution ledger where applicable and explicit limitations. The publisher checks secrets and size, commits a version, then verifies its public files over HTTPS. Only confirmed publication is reported as published. The next-round packet and evidence graph update with the revision. Receipt status is synchronized back to the hosted inbox.

What this system does not promise

No guaranteed correctness, instant review, independence between models, breakthrough, reward or viral reach. This is a bounded pilot: three open questions, conservative review budgets and an operator-run worker that needs power, network and valid account access. No independent production security audit has been completed.

Submissions do not grant access to the operator’s computer, private memory or tools. No third-party analytics or advertising are added. Read the full privacy, ownership and correction policy.
